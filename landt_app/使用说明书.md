# 蓝电（LAND）测试柜远程控制上位机 — 使用说明书

> 版本 v1.0　｜　适用协议：《蓝电远程控制及数据获取协议 V3.0》
> 适用设备：8 通道（1×8）测试柜　｜　通讯方式：HTTP（默认端口 7777）

---

## 一、这套软件是做什么的

本软件通过蓝电官方的 **HTTP 协议**远程控制测试柜，实现协议文档里的**全部功能**：

| 协议接口 | 功能 | 软件对应操作 |
|---|---|---|
| `/OpearMon/control` | 远程 **启动 / 续接 / 停止** 通道（含电池条码、活性质量、比容量、极性、备份方案） | 勾选通道 → 「▶启动 / ⏯续接 / ■停止」 |
| `/QueryChlStatus/control` | 获取通道**状态**（测试中/停止/完成/故障/无状态） | 「立即刷新」或「自动刷新」 |
| `/QueryChlRP/control` | 获取通道**实时参数**（电压/电流/容量/循环/工步/温度等） | 「立即刷新」或「自动刷新」 |

---

## 二、工作原理（务必先看懂这张图）

```
 ┌──────────┐   COM7(串口)   ┌─────────────────────────┐   HTTP:7777   ┌──────────────┐
 │  测试柜   │ ────────────► │ 蓝电监控软件            │ ◄──────────► │ 本软件        │
 │ (硬件)    │               │ LANDMon / CLANDTestDlg  │              │ 远程控制上位机 │
 └──────────┘               │ （本机开放 7777 端口）   │              └──────────────┘
                            └─────────────────────────┘
```

- **COM7 是「蓝电监控软件 ↔ 测试柜硬件」之间的连接**，不是本软件直接连串口。
- 本软件是通过 **HTTP** 去跟「蓝电监控软件 `LANDMon.exe`」对话，由它再去控制测试柜。
- 所以运行本软件前，**必须先把蓝电监控软件 `LANDMon.exe` 打开并连上测试柜（COM7）**。
  （注意：`CLANDTestDlg.exe` 只是启停小工具，提供 7777 HTTP 服务的是 `LANDMon.exe`。）

> ⚠️ **重要：HTTP 服务不一定绑定在 `127.0.0.1`。**
> 实测本机 `LANDMon.exe` 的 7777 端口是**绑定在局域网 IP（如 `172.16.2.233`）**上的，
> 所以填 `127.0.0.1` 会报「目标计算机积极拒绝」。
> **解决办法：点顶部「自动查找主机」按钮即可**——软件会自动在本机所有网卡 IP 上探测 7777 端口，
> 找到后自动填好。程序启动时也会自动执行一次查找，通常无需手动操作。
>
> 若是**另一台电脑**连本机，则在那台电脑的本软件里把主机 IP 填成本机的局域网 IP（如 `172.16.2.233`），
> 并确保两机同一局域网、本机防火墙放行 7777 端口。

## 三、通道号怎么设置（重点）

协议用两个字段共同定位一个通道：

- **nBox（箱号）**：基于 1。整机只有 1 个箱体时填 `1`。
- **nChl（通道号）**：基于 1，范围 **[1, 8]**。

软件界面里每一行就是一个通道，行首「通道标识」会实时显示成蓝电格式 `00X_1 … 00X_8`
（含义：`箱号(3位)_通道号`，例如 `002_8` = 第 2 箱第 8 通道）。

> ⚠️ **重要：一台 LANDMon 可能管理多个「箱体」。**
> 实测本设备 `LANDMon.exe` 里存在多个箱体（nBox = 1,2,3,…），**但真正接了硬件的只有其中一个**
> （本机实测为 **箱 2**：通道 1、2 有状态，其余为「无状态」）。其它空箱体的通道全是「无状态」。
>
> **软件已自动处理**：连接/自动查找后，会扫描出所有箱体，并**自动选中“有有效通道”的那个箱**
> （顶部「箱号 nBox」是一个下拉框，列出了所有箱体，你也可以手动切换）。
> 你的 8 个通道（1×8）就在被自动选中的那个箱里显示为 `00X_1 … 00X_8`。

## 四、快速上手（启动一个通道）

1. **打开蓝电监控软件 `LANDMon.exe`**，确认它已通过 COM7 连上测试柜。
2. **打开本软件**。程序会自动「查找主机 + 扫描箱体」，看到顶部变绿「● 已连接」，
   且「箱号」已自动选到有效箱（如箱 2）。
   - 若没自动连上，手动点一次 **「自动查找主机」**。
3. 在表格里（当前显示的就是所选箱的 8 个通道）：
   - 勾选要启动的通道（如通道 1）；
   - 在该行「条码」框里**输入电池条码**（如 `BAT-0001`）；
   - （可选）填活性质量 `ActMass`、比容量 `SpeCap`；
   - 在中间「启动参数」里选好 **测试工艺(.spi)** 文件和 **备份目录**；
   - 点 **「▶ 启动选中」**。
4. 看到日志「[成功] 启动成功 (nCode=0)」即启动成功。表格状态会变绿「测试中」。

> **停止** / **续接**：勾选通道后点对应按钮即可，条码/工艺可留空。
>
> 💡 **关于刷新频率（重要）**：LANDMon 服务端有「防频繁请求」限流，请求太密会被拒绝
> （返回 `nCode=-1, Reject frequent requests`）。本软件已内置**自动限流与退避重试**，
> 默认刷新间隔 **5 秒**；如日志仍提示 QC 限流，请把「间隔(秒)」调大到 8~10 秒。

## 五、界面说明

### 1. 连接设置（最上方）
- **主机 IP / 端口**：蓝电软件的 HTTP 服务地址，端口默认 `7777`。
- **自动查找主机**：在本机所有网卡 IP 上探测 7777，自动填入能连通的主机（推荐）。
- **测试连接**：用当前填写的主机 IP 验证能否连上。
- **自动刷新 + 间隔(秒)**：勾选后按间隔自动刷新通道状态与参数（默认 5 秒，勿设太小）。
- **立即刷新**：手动刷新一次。

### 2. 启动参数（中间，仅「启动」时必须）
| 字段 | 说明 |
|---|---|
| 箱号 nBox | 箱体号，基于 1 |
| 极性 | 正极性 / 反极性（对应协议 `CycModeReverse` 0/1） |
| SchemeFlag | 4 位备份文件名组合标志，点「?」看详解，默认 `1210` |
| PartA 前缀 | 备份文件名前缀（SchemeFlag 第1位=0 启用时才生效），上限 44 字符 |
| 测试工艺(.spi) | **启动必填**，必须是「蓝电软件所在电脑」上真实存在的 `.spi` 路径 |
| 备份目录 | 数据备份目录 |

### 3. 通道列表（1×8，每行一个通道）
- **选**：勾选参与批量操作。
- **通道标识**：自动生成的 `001_1…001_8`。
- **条码 / 活性质量 / 比容量**：启动参数，按通道分别填写。
- **状态**：彩色显示　测试中(绿)／停止(灰)／完成(蓝)／故障(红)／无状态(浅灰)。
- **电压V / 电流mA / 容量 / 循环 / 工步 / 工步时间 / 温度 / 备份文件名**：实时参数。

顶部按钮：`全选` `全不选` `▶启动选中` `⏯续接选中` `■停止选中`。

### 4. 运行日志（最下方）
每次操作、每条返回码都会记录。**判断成功与否以 `nCode=0` 为准**（协议规定）。

## 六、SchemeFlag（备份文件名组合）详解

SchemeFlag 是 **4 位数字**，决定备份文件名怎么拼：

| 位 | 取值 | 含义 |
|---|---|---|
| 第 1 位 | 0 / 1 | 启用 / 弃用 **PartA**（前缀名） |
| 第 2 位 | 0/1/2/3 | 弃用PartB / 通道启动日期 / **电池条码** / 电池条码_通道启动时刻 |
| 第 3 位 | 0/1/2 | 弃用PartC / **通道号**(如 `_003_8`) / PartC_Alias |
| 第 4 位 | 0 / 1 | 名字顺序 AB_C / A_C_B |

**示例 `1210`**：弃用 PartA、用电池条码作 PartB、用通道号作 PartC、顺序 AB_C
→ 备份文件名形如 **`电池条码_001_8`**（这也是默认值，最常用）。

---

## 七、通道状态码 / 错误码对照

- **通道状态 nStatus**：`0`测试中　`1`停止　`2`完成　`3`故障　`4`无状态
- **操作返回 nCode**：`0`=成功；**负数**=失败，`strMsg` 为失败原因。

## 八、无真机时如何自测（可选）

软件附带一个「蓝电协议模拟服务器」，可在**没有测试柜**时验证界面与流程：

1. 双击运行 `蓝电协议模拟服务器.exe`（或 `python landt_mock_server.py`）。
2. 本软件主机 IP 填 `127.0.0.1`、端口 `7777`。
3. 即可模拟 8 通道的启动/停止/状态/参数（数据为随机演示值）。

> 正式使用真机时，请关闭模拟器，改连蓝电监控软件。

## 九、常见问题

| 现象 | 可能原因与解决 |
|---|---|
| **「目标计算机积极拒绝」/ 连不上 127.0.0.1** | HTTP 服务绑定在局域网 IP 而非 127.0.0.1。**点「自动查找主机」**让软件自动找到正确 IP（如 172.16.2.233）。 |
| 连接失败 / 一直「未连接」 | `LANDMon.exe` 没开、没连上 COM7、端口填错、或防火墙拦截 7777 |
| 日志出现 `Reject frequent requests / QC` | 服务端限流，请求太频繁。软件会自动退避重试；可把「刷新间隔」调大到 8~10 秒 |
| 启动返回负数 nCode | `.spi` 工艺路径在蓝电软件电脑上不存在、通道已在测试中、参数非法 |
| 表格全是「无状态」/看不到通道 | 当前「箱号」是空箱。用顶部箱号下拉框切到有效箱（软件一般会自动选中，如箱 2） |
| 状态不更新 | 勾上「自动刷新」，或点「立即刷新」；确认「箱号」与实际一致 |
| 跨电脑连不上 | 确认两台电脑同一局域网，且蓝电软件电脑防火墙放行 7777 端口 |
| 中文/数据乱码 | 本软件内部使用 UTF-8，正常不会乱码；如异常请反馈日志内容 |
